| File | Status |

| `best_7.onnx` | Earlier snapshot |

The team finished first in Germany and 24th overall with `best_8.onnx` as the
final uploaded model. This tournament result is not an isolated benchmark of
that snapshot: earlier models were also submitted during the event.

Snapshot numbers show version order, not game counts or measured strength.
A later snapshot is not necessarily stronger. No head-to-head comparison
results are claimed here.
