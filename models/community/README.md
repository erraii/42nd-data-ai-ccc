# Peer-shared models

Models in this directory are credited to their source contributor folders.
The available local inventory includes `zak/apex_predator.onnx` and
`zak/eray_killer.onnx`. The collector imports the actual binaries only when
`--include-shared-models` is requested.

These files are shared peer contributions, not claimed as the product of this
repository's training run. Retain the contributors' publication permission and
any supplied model-license terms.
